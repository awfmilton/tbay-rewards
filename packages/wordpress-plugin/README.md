# TBAY Rewards — WordPress plugin

The `tbay-rewards/` directory is the plugin. Install it by copying that folder
into `wp-content/plugins/`, or zip it for the WordPress uploader:

```bash
cd packages/wordpress-plugin
zip -r tbay-rewards.zip tbay-rewards -x '*.DS_Store'
```

Full documentation: [docs/WORDPRESS.md](../../docs/WORDPRESS.md).
